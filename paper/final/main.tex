\begin{abstract}
Inspired by weight-space programming, we ask whether LLMs encode usable Newtonian dynamics.
We release an exact simulator, ID/OOD benchmarks, LoRA and probe-guided adapters, controlled probes, a selective simulator-call agent, and a tiny-network weight-reading pilot.
Code and artifacts: \url{https://github.com/bishoymoussa/Phil}.
\end{abstract}
